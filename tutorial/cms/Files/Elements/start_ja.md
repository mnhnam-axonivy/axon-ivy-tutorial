# Start と Process End

`RequestStart` · `TaskEnd` · `TaskEndPage` · Axon Ivy 14.0

## どんな要素で、いつ使うか

**Start** はプロセスが始まる場所です。開始されるたびに、Axon Ivy は新しいケースとタスクを作成します。パレットの *Event & Gateway* ドロワーにあります（公式リファレンスでは Request Start と呼ばれています）。

Start は次の2つの方法で開始でき、それぞれ個別にオン／オフできます。

- **リクエストで**: リンク、開始できるプロセスの一覧ページ、またはリンクを呼び出す別のシステム
- 別のプロセスの **Trigger Step で**（このガイドのパート6）

対になるのは終了です。Start で始まるプロセスは、Process End か Process End Page で終わります。設定するものが少ないので、下の「詳細」の最後に短い節があります。

人やリンクがプロセスを開始するのでなければ、別の開始要素を使います。

| プロセスが始まるのは… | 使う要素 |
| --- | --- |
| 別のプロセスが呼び出し、その結果を待つとき | Sub Process Start（パート3） |
| シグナルが送られたとき | Signal Start（パート6） |
| タイマーや外部のイベントで | Program Start（パート7） |
| エラーを処理するため | Error Start（パート3） |

## 詳細

Start のインスクリプションには **一般**、**開始**、**リクエスト**、**トリガー**、**タスク**、**ケース** の6つのタブがあります。

### 一般

| フィールド | 役割 |
| --- | --- |
| 名前／説明 → 表示名 | キャンバスに表示される名前。公式リファレンスは「すべての要素に必ず名前を付ける」ことを勧めています。 |
| 名前／説明 → 説明 | エディターのツールチップに表示されます。Markdown を使えます。 |
| 手段／ドキュメント | 要素に関係するドキュメントへの参照。 |
| タグ | 自由なキーワード。Start では、`DEMO` を付けるとプロジェクトを Designer にインポートしたときにプロセスが自動で開き、`DEPRECATED` を付けると呼び出し元に非推奨の警告が表示されます。 |

### 開始

| セクション | 役割 |
| --- | --- |
| **シグネチャ** | 開始の名前。大文字と小文字が区別され、使えるのは英字、数字、アンダースコアだけです。 |
| **入力パラメーター** | パラメーターごとに1行: 名前、タイプ、説明。リストは空でも構いません。名前と、タイプとその順序を合わせたものが *シグネチャ* です。例: `bookRoom(String,Number)` |
| **マッピング** | プロセスデータの属性ごとに1行（`out.<属性>`）。式が属性に値を与えます。多くは `param.<名前>` です。式のない行は、その属性を初期値のままにします。 |
| **コード** | マッピングの後に、同じ変数で実行される IvyScript。 |

Start のマッピングとコードで使える変数:

| 変数 | 内容 |
| --- | --- |
| `param` | 入力パラメーター。1つずつフィールドになります: `param.room`。Start の中だけで使えます。 |
| `out` | Start から出ていくプロセスデータ。 |
| `ivy` | 環境: `ivy.log`、`ivy.cms` など。 |
| `in` | **使えません。** Designer は `Variable 'in' cannot be resolved` と報告します。 |

パラメーターは名前とタイプで宣言します。リファレンスのヒント: 名前の欄に `myDate:Date` と入力するとタイプも同時に設定でき、タイプなしでコロンだけを付けると String になります。

### リクエスト

| フィールド | 既定値 | 役割 |
| --- | --- | --- |
| はい、これは HTTP-Request / -Link で起動できます | オン | オフにすると、リンクで Start を開始できなくなります。ほかのフィールドは非表示になります。 |
| 開始リンク | `<シグネチャ>.ivp` | Start を呼び出すリンク。必ず `.ivp` で終わり、プロセス内で一意です。パラメーターはこれに付け加えます: `bookRoom.ivp?room=Matterhorn&people=4` |
| 開始リストに表示する | オン | ユーザーが開始できるプロセスの一覧ページに、このプロセスを表示するかどうか。 |
| 名前、説明、カテゴリー | 空 | その一覧でのプロセスの表示。「ケース」タブで別に設定しない限り、ケースにも使われます。 |
| カスタムフィールド | なし | 開始リスト向けの情報。例えば `cssIcon` でアイコンを指定します。Axon Ivy が開始を扱う方法は変わりません。 |
| 権限 → ロール | Everybody | プロセスを開始するユーザーは、これらのロールのいずれかを持っている必要があります。 |
| 権限 → 匿名を許可する | オン | ログインせずにプロセスを開始できるようにします。 |
| 権限 → 違反エラー | | ユーザーがロールを持っていないときにスローされるエラー。Error Start でキャッチできます。 |

> リファレンスの警告: 新しいプロセスや開始要素を作成すると、匿名のアクセスが許可された状態になります。公開環境や本番環境にデプロイする前に、これらの設定を見直して制限してください。

### トリガー

| フィールド | 役割 |
| --- | --- |
| はい、これはトリガーアクティビティで開始できます | 別のプロセスの Trigger Step からこのプロセスを開始できるようにします。既定ではオフです。 |
| 担当、オプション（このプロセスをトリガーしたビジネスケースに添付する、遅延） | トリガーが作るタスクを誰がいつ受け取るか。上のオプションがオンのときだけ表示されます。パート6で説明します。 |

### タスク

Start が作るタスクの名前、説明、カテゴリー、優先度、有効期限、カスタムフィールド、コード。**作成時にタスクを継続する** オプションは、ケースとタスクをすぐに保存します。匿名ユーザーが許可されていない場合にのみ機能します。リンクで開始されたタスクはすぐに処理されるので、これらの設定の多くはトリガーで開始される Start でだけ意味があります（パート6）。

### ケース

ケースの名前、説明、カテゴリー、カスタムフィールド。設定がなければ、ケースは「リクエスト」タブの名前、説明、カテゴリーを使います。

### 実行時

1. リクエストが届きます。各入力パラメーターは、リンクの同じ名前の値から `param` のフィールドになります。型に合わないテキストはログに記録され、パラメーターは値なしで届きます。Number に `?people=abc` を渡すと、ランタイムログに `ParameterMapToObjectFiller: Could not convert string 'abc' to a Number.` と書かれ、プロセスは 0 で続きます。Boolean が `true` になるのは `true`（大文字小文字は問わない）のときだけで、`yes` は `false` です。
2. マッピングの行が1行ずつ順にプロセスデータに代入されます。
3. コードが実行されます。
4. トークンが先に進みます。この後に残るのはプロセスデータにあるものだけで、`param` はなくなります。

パラメーターの変換、行の順序、予約された `lang` はドキュメントに記載がありません。2026-11-16 に Designer のエンジン 14.0.1 で確認したものです。

### 対になる要素: Process End と Process End Page

どちらもプロセスを終了します。リファレンスの言葉では:

| 要素 | 役割 | インスクリプション |
| --- | --- | --- |
| **Process End** | 「この要素は現在のプロセスを終了します。」 | 「一般」だけ |
| **Process End Page** | 「この要素は現在のプロセスを終了し、ダイアログページを表示します。」 | 「一般」と **終了ページ**: 「ケースがこの終了ページ要素で終わるときに表示される Web ページ」。横の **ファイルを開く** でページを開きます。 |

プロセスを開始した人に、誰にとっても同じ最後のページを見せたいときは Process End Page を使います。確認やお礼などです。それ以外は Process End を使います。プロセスに複数の終了があるときは、それぞれに結果を表す名前を付けます。「注文完了」「注文却下」のように。

「ページはコンテンツ管理システムからも、Web コンテンツのディレクトリからも参照できます」。このガイドの例は `webContent` のファイル `view/tutorial/part2/parking-booked.html` です。JSF のページ（`.xhtml`）は「webcontent/view ディレクトリに置く必要があります」。

ページは静的です: 「静的な JSF ページをワークフローの終了ページとして使っても、ケースとタスクのコンテキストにはアクセスできません」。ケースのデータを見せるには、終了の前に User Dialog を使います（パート5）。ほかの2つの終了はパート3で扱います。ハンドラーが捕まえられるエラーで終了する Error End と、呼び出し元のプロセスに戻る Sub Process End です。

## よくある質問

**開始するときにプロセスへ値を渡すには？**
「開始」タブで入力パラメーターを宣言し、プロセスデータの属性にマッピングします。呼び出し側はそれをリンクに付け加えます: `bookRoom.ivp?room=Matterhorn`。Trigger Step は自分のマッピングで渡します（パート6）。

**開始パラメーターが、プロセスの後半で空になっているのはなぜ？**
ほとんどの場合、マッピングのどの行もそれを使っていないからです。パラメーターは `param` に届きますが、プロセスデータにコピーするものがありません。Designer はこれを警告しません。「開始」タブでその属性の行を確認してください。下の、予約された名前の間違いも参照してください。

**Start で `in` を使える？**
使えません。Start のマッピングとコードにあるのは `param` と `out` だけです。`in.room = …` ではなく `out.room = param.room;` と書きます。

**パラメーターを変えると、呼び出し元はどうなる？**
タイプとその順序はシグネチャの一部です。どちらかを変えると、この開始を呼び出すすべての要素（例えば Trigger Step）を更新する必要があります。ほかの人が保存したリンクは名前を使っているので、プロセスが使われ始めたら名前は変えないでください。

**誰がプロセスを開始できる？**
「権限」にあるロールのいずれかを持つ人です。**匿名を許可する** がオンなら誰でも開始できます。新しい開始ではオンになっています。

**開始をプロセスの一覧に出さないには？**
「リクエスト」タブで **開始リストに表示する** をオフにします。開始リンクはそのまま使えます。

**終了ページに、予約した内容を表示できる？**
いいえ。終了ページとして使っても、静的なページはケースとタスクにアクセスできません。データは終了の前の User Dialog で表示します（パート5）。

## よくある間違い

### パラメーターを宣言したが、マッピングしていない

- *症状:* リンクには値があるのに、Start の後で属性が空か 0 になっている。
- *原因:* マッピングのどの行も `param.<名前>` を代入していない。実行は失敗しない。
- *直し方:* 行を追加する。例: `out.people` ← `param.people`。[ウォークスルー 2.3](#/walkthrough/2.3) で確認できます。

### Start で `in` を使う

- *症状:* Designer が `Start 'out.room': Variable 'in' cannot be resolved`（コードでは `Start code: …`）と報告する。
- *原因:* Start には、まだ入ってくるデータがない。
- *直し方:* `param` から読み、`out` に書く。[ウォークスルー 2.3](#/walkthrough/2.3) で確認できます。

### パラメーター名のつづり間違い

- *症状:* Designer が `Start 'out.room': Field rooms not found for class <java.lang.String room,java.lang.Number people>` と報告する。
- *原因:* 式が宣言されていないパラメーターを指している。メッセージのクラスに、宣言されているパラメーターが並んでいる。
- *直し方:* 並んでいる名前のどれかを使う。フィールドで Ctrl+Space を押すと候補が出ます。

### 予約された名前のパラメーター

- *症状:* `lang` という名前のパラメーターが常に空になる。
- *原因:* 一部のリクエストパラメーターは Axon Ivy 自身が使っている。`lang` については Axon Ivy コミュニティに報告があり、エンジン 14.0.1 でも `?lang=de` は空の String として届く。
- *直し方:* `language` のような、より具体的な名前を付ける。

### 匿名のアクセスが有効なまま

- *症状:* 公開された Engine で、リンクを知っている誰もがプロセスを開始できる。
- *原因:* 新しい開始では **匿名を許可する** がオンになっている。
- *直し方:* オフにして、プロセスを開始できるロールを選ぶ。

### 終了ページにケースのデータ

- *症状:* 終了ページで、何を予約・注文・承認したのかを示せない。
- *原因:* Process End Page のページは静的で、ケースとタスクのコンテキストにアクセスできない。
- *直し方:* データは終了の前の User Dialog で表示し、終了ページは誰にとっても同じ内容に使う。[ウォークスルー 2.5](#/walkthrough/2.5) で確認できます。
